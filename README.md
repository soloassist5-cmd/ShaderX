# Backrooms Event Shaders

Шейдерпак для ивента Backrooms по мотивам фильма. Он делает картинку похожей на кассету из найденной видеокамеры и даёт каждому этажу свой стиль.

| Этаж | Как выглядит |
|---|---|
| **Level 0** | Моно-жёлтые стены, лёгкая жёлтая дымка вдали, гудящие и иногда моргающие лампы, свечение потолочных панелей |
| **Level 1** | Холодный серо-синий бетон, полутьма, свет пропадает уже через несколько десятков блоков |
| **Level 2** | Ржаво-коричневый тон, тьма сразу за пределами света, сильное мерцание |
| **Poolrooms (Level 37)** | Белый и бирюзовый тон, пересвет, мягкое «сонное» свечение, лампы не мерцают |
| **Level !** | Красный свет, тревожная пульсация, тряска камеры, сильная аберрация |

На всех этажах работает эффект камеры: VHS-полоса трекинга, дрожание строк, зерно, строки развёртки, растекание цвета, хроматическая аберрация, виньетка и надписи `● REC`, `SP` и счётчик плёнки.

## Как определяется этаж

Шейдер не видит блоки и не знает, где какой этаж. Он смотрит на **высоту камеры игрока (Y)**. Поэтому этажи должны лежать на разной высоте (как обычно и строят). Если этажи стоят на одной высоте, но далеко друг от друга, перенесите их по вертикали или включайте нужный этаж вручную.

Высоты настраиваются в игре: **Настройки → Видео → Шейдеры → Backrooms → Настройки → «Высоты этажей»**.

1. Встаньте на этаж и нажмите F3. Посмотрите координату Y: это ноги игрока, камера примерно на 1.6 блока выше.
2. Для каждого этажа задайте `от Y` (уровень пола) и `до Y` (уровень потолка).
3. Значения по умолчанию сделаны для примера: Level 0 — 64–71, Level 1 — 56–63, Level 2 — 48–55, Poolrooms — 40–47, Level ! — 32–39.

Вне всех диапазонов (например, в лобби на поверхности) картинка обычная, только с эффектом камеры. Его можно выключить опцией «Камера вне этажей».

Параметр **«Этаж»** может принудительно включить один стиль. Это удобно для проверки или если ваши этажи стоят на одной высоте.

Чтобы у всех игроков всё совпадало, настройте пак у себя и раздайте файл `shaderpacks/Backrooms-Shaders.zip.txt`, который Iris создаёт рядом с паком: в нём сохранены настройки.

## Установка (для каждого игрока)

На ванильном сервере шейдеры нельзя включить игрокам со стороны сервера: каждый ставит их у себя.

1. Установите [Fabric](https://fabricmc.net/use/) для вашей версии игры.
2. Установите [Iris](https://modrinth.com/mod/iris) и [Sodium](https://modrinth.com/mod/sodium) для 26.1.2 (Iris Installer ставит всё сам).
3. Положите `Backrooms-Shaders.zip` в папку `.minecraft/shaderpacks`.
4. В игре: Настройки → Видео → Шейдеры → выберите пак.

Сборка zip из репозитория: `./build.sh`.

## Советы для атмосферы

- Яркость в настройках игры лучше держать «Мрачно» (Moody), иначе тьма на Level 1 и Level 2 будет слабее.
- Свечение срабатывает на всём ярком, поэтому светящиеся блоки на потолке (морские фонари, светокамень, лампы) будут сиять как люминесцентные панели.
- Если эффект камеры кому-то мешает или укачивает, уменьшите «Сила VHS» или выключите «Эффект VHS-камеры».
